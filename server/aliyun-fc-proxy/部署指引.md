# 阿里云函数计算部署指引（约 10 分钟，一次性配置）

目标：部署一个稳定的抓取代理，解决公司网络拦截公共 CORS 代理导致"全网比价"失败的问题。

## 一、创建函数

1. 打开 https://fcnext.console.aliyun.com/ 并登录（需已实名认证的阿里云账号）。
2. 首次使用会提示开通函数计算服务，按提示开通（有免费额度，本用途用量极小，基本不产生费用）。
3. 左侧菜单选「函数」→「创建函数」。
4. 按以下方式配置：
   - 创建方式：**使用内置运行时**
   - 函数名称：`bps-price-proxy`（可自定义）
   - 运行时：**Node.js 18**
   - 请求处理程序类型：**处理 HTTP 请求**
   - 触发器：选择创建 **HTTP 触发器**，认证方式选 **无需认证**，勾选"需要启用"即可
   - 其余选项保持默认，点击「创建」
5. 进入函数详情 → 「代码」页签 → 在在线编辑器中打开 `index.js`，把本目录 `index.js` 的全部内容粘贴进去，点击「部署」。

## 二、获取公网地址并测试

1. 部署成功后，函数详情页顶部可看到「公网访问地址」，形如：
   `https://bps-price-proxy-xxxx.cn-hangzhou.fcapp.run`
2. 在浏览器打开测试（注意带上路径和参数）：
   `https://你的公网地址/api/search?src=jd&kw=不锈钢板304`
3. 预期返回：`{"ok":true,"src":"jd","items":[{"title":"...","price":199.0,"img":"https://img14.360buyimg.com/...","url":"https://item.jd.com/....html"}, ...]}`

## 三、接入网站（二选一）

- 方式 A（推荐）：把公网地址发给黄康，由我更新到网站代码里，全网用户直接生效。
- 方式 B（立即生效）：在网站地址后加 `?fc=你的公网地址` 打开一次，例如：
  `https://dashu-commits.github.io/building-price-station/?fc=https://bps-price-proxy-xxxx.cn-hangzhou.fcapp.run`
  地址会自动保存到浏览器本地，之后无需再带参数。

## 四、验证

打开建材价格情报站 → 随便点一个材料 → 点「🔍 全网比价」→ 输入关键词（如"戴尔电脑"）→ 搜索。
成功时会出现商品卡片（图片 + 标题 + 价格）；若仍显示"抓取失败"，把状态栏文字截图反馈。

## 常见问题

- **返回反爬页面 / items 为空**：京东对函数计算 IP 偶有风控，可在函数里给请求头补一个有效 Cookie（登录京东后复制），需要时联系我调整代码。
- **触发器要求认证**：创建 HTTP 触发器时务必选「无需认证」，否则网页调用会 403。
- **费用**：函数计算按调用次数和时长计费，本场景每天几十次调用，免费额度内，基本为 0 元。
